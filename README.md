# YTKiller (working name)

Static prototype for Project YouTube Killer, ready for GitHub Pages (no build step).

- `index.html` homepage, `watch.html` player, `channel.html`, `rules.html`, shared `style.css`
- The watch page plays any Internet Archive item: `watch.html?v=<archive identifier>`
- Add videos to `videos.js`

Deploy: push these files to a repo, then Settings > Pages > deploy from the main branch root.
