# RawReel

Videos that stay up. A static site for GitHub Pages, with no build step.

- `index.html` is the homepage and `watch.html` is the player. There's also `channel.html`, `rules.html`, `upload.html`, `import.html` and `about.html`, all sharing `style.css`.
- The watch page plays any Internet Archive item with `watch.html?v=<archive identifier>`, or a clip.place video with `&host=clipplace`.
- To add videos, edit `videos.js`.
